# 📊 Dashboard de Análise de Vendas – Walmart Dataset

Este projeto apresenta um dashboard interativo desenvolvido no **Power BI** com foco na análise estratégica de vendas, clientes e desempenho de lojas a partir de um dataset público do Walmart.

O objetivo foi transformar dados brutos em **insights claros e acionáveis**, apoiando decisões de negócio.

---

## 🔍 Objetivo

Estruturar, analisar e visualizar dados de vendas para:

- Identificar padrões de desempenho ao longo da semana  
- Avaliar produtos e categorias mais rentáveis  
- Analisar comportamento de clientes  
- Comparar performance entre lojas  
- Apoiar decisões estratégicas baseadas em dados  

---

## 🧠 Estrutura Analítica do Projeto

O dashboard foi dividido em três principais visões:

### 📊 1. Desempenho de Vendas

- Faturamento total  
- Volume de vendas por dia da semana  
- Produtos mais vendidos por período  
- Análise de vendas em feriados  
- Método de pagamento mais rentável  

**Insight gerado:** identificação de padrões de pico de vendas e oportunidades de otimização comercial.

---

### 👥 2. Análise de Clientes

- Perfil de consumo por faixa etária  
- Categorias mais consumidas  
- Distribuição por nível de fidelidade  
- Identificação de segmentos mais lucrativos  

**Insight gerado:** entendimento do comportamento de compra e oportunidades de segmentação estratégica.

---

### 🏬 3. Performance das Lojas

- Comparativo de faturamento entre unidades  
- Volume de vendas por loja  
- Desempenho por categoria de produto  
- Identificação de lojas com maior eficiência operacional  

**Insight gerado:** análise comparativa para direcionamento estratégico e tomada de decisão gerencial.

---

## 🔄 Processo de Desenvolvimento

Durante o projeto foram realizadas as seguintes etapas:

1. Organização e tratamento dos dados  
2. Definição de métricas e KPIs relevantes  
3. Modelagem dos dados no Power BI  
4. Criação de medidas utilizando DAX  
5. Construção de visualizações interativas  
6. Aplicação de storytelling analítico para facilitar interpretação executiva  

---

## 📈 Principais KPIs Desenvolvidos

- Faturamento Total  
- Volume de Vendas  
- Ticket Médio  
- Produtos Mais Vendidos  
- Performance por Loja  
- Distribuição por Perfil de Cliente
